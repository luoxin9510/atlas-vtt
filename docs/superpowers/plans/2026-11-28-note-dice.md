  - nothing changes while a map is open.

## Task 1: a workspace dice layer and a default off-map roller

1. **One app-level off-map roller.** A small service replaces the scattered silent paths. It:
   - rolls through the same builder as maps (checks, contests, GM-only through `rollVisibility`);
   - picks the dice set from the note's collection, else the library default (decision 7);
   - emits on an app-level bus;
   - keeps the last 20 rolls in memory.
2. **The layer.** A per-window host mounts `DiceRollDisplay`, subscribed to that bus, in the window
   where the roll was made (popouts included). It mounts lazily, on the first roll.
3. **Surfaces without their own `OffMapRolls`** (reading-view statblock fences, note dice and check
   links, the sidebar) use the default roller. The pane and the encounter builder keep theirs.

## Task 2: rule packs and online

- Rule-pack `rollDice`, `rollCheck` and `rollContest` with no map open go through the roller, so they
  show.
- `RollShare` also listens to the app-level bus. A GM-only roll leaves a secret entry, as on a map.
